## ♡ About LunaCycle

**LunaCycle** is a personal menstrual cycle tracking web application built to help users keep track of their periods, understand their cycle patterns, and maintain a personal record of their wellbeing.

Designed with a soft pink, lavender, and cream aesthetic, LunaCycle combines practical tracking features with a calm and welcoming user experience.

It's more than a calendar. It's a small reminder to listen to your body.

## 💻 Getting Started

Want to explore LunaCycle locally?

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate into the project

```bash
cd LunaCycle
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install django
```

If a `requirements.txt` file is available, use:

```bash
pip install -r requirements.txt
```

### 6. Apply migrations

```bash
python manage.py migrate
```

### 7. Start the development server

```bash
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
